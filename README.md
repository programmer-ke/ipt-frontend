# The Interplanetary Token

The Web interface for the [Interplanetary Token][contract] demo.

[contract]: https://github.com/programmer-ke/interplanetary-token

Powered by 🏗 [Scaffold-ETH 2][scaffoldeth]

[scaffoldeth]: https://github.com/scaffold-eth/scaffold-eth-2

## Quickstart

To get started with follow the steps below:

1. Install dependencies if it was skipped in CLI:

```
cd ipt-frontend
yarn install
```
2. Start your NextJS app:

```
yarn start
```

Visit your app on: `http://localhost:3000`. You can interact with your
smart contract using the `Debug Contracts` page. You can tweak the app
config in `packages/nextjs/scaffold.config.ts`.
